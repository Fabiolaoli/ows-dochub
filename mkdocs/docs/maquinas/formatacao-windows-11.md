# Formatação do PC (Windows 11)

Instalação e configuração inicial do Windows 11 em ambiente corporativo, desde a inicialização pelo pendrive bootável até as configurações básicas de acesso ao sistema.

## Inicialização pelo pendrive bootável

1. Inserir o pendrive bootável do Windows 11 na máquina e pressionar a tecla `F12` até acessar o menu de boot.
2. Selecionar o dispositivo "PenDrive Kingston".

## Processo de Instalação do Windows 11

1. Selecionar a opção "Instalar Windows 11 (x64)".
2. Escolher a opção "Personalizada: Instalar apenas o Windows (avançado)".
3. Excluir todas as partições existentes no disco.
4. Criar uma nova partição para instalação do sistema operacional.
5. Clicar em "Avançar" e aguardar a conclusão da instalação.

## Configuração Inicial do Sistema

1. Selecionar a opção "Configurar para corporativo ou estudante".
2. Clicar em "Opções de entrada".
3. Selecionar a opção "Ingresso no domínio".

## Configuração de Acesso

1. Realizar o login como Empresa/Colaborador.
2. Definir o nome de usuário como "Admin".
3. Não é necessário configurar senha neste momento.
