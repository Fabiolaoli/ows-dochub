# Tarefa de Redução de Risco do Bitdefender

Identificação de usuários através de relatórios do Bitdefender e validação no Active Directory, para solicitação de atualização de aplicações.

## Consulta do Hostname no Wrike

1. Acessar o chamado no Wrike.
2. Abrir o arquivo Excel anexado.
3. Copiar o **Host Name** informado.

## Localização da Máquina no Bitdefender

1. Acessar o Bitdefender.
2. Navegar pelos seguintes diretórios:
   - Redes
   - OLOS TECNOLOGIA
   - EMPRESAS
   - Olos Tecnologia
   - Computadores e Grupos
   - Notebooks BitLocker
3. Colar o Host Name no campo de pesquisa (**Nome**).
4. Após localizar o equipamento, clicar sobre o Host Name identificado.
5. Acessar a opção **Relatório da Análise**.
6. Verificar os relatórios:
   - Análise Completa; ou
   - Análise Rápida.

   > **Observação:** Pode ser necessário abrir mais de um relatório até localizar o usuário correspondente.

7. Identificar o usuário através do caminho exibido no relatório.

   Exemplo: `C:\Users\edusal`

## Validação do Usuário no Active Directory

1. Acessar o Active Directory.
2. Navegar até: `intra.olos.com.br`
3. Clicar com o botão direito sobre a pasta **OLOS**.
4. Selecionar a opção **Localizar**.
5. Inserir o nome do usuário identificado no relatório (exemplo: `edusal`).
6. Localizar e validar o nome completo do colaborador.

## Contato com o Colaborador

1. Entrar em contato com o usuário através do Microsoft Teams.
2. Solicitar a atualização da aplicação indicada no chamado.
