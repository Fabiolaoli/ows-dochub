# Atribuir licença ao usuário

Atribuição de licenças no Microsoft 365 e liberação de acesso ao sistema Wrike por meio do Microsoft Azure. As etapas garantem que o colaborador tenha acesso adequado às ferramentas corporativas necessárias para execução de suas atividades.

## Configuração de Licença – Microsoft 365 Admin Center

### Acesso ao Portal Administrativo

Acessar o portal administrativo da Microsoft 365 Admin Center.

### Pesquisa do Colaborador

Utilizar a barra de pesquisa para localizar o colaborador pelo nome.

### Atribuição de Licença

1. Acessar a seção **Licenças e Aplicativos**.
2. Localizar e atribuir a licença: **Microsoft 365 Empresas**.
3. Clicar em **Guardar Alterações** para concluir o processo.

## Configuração de Acesso – Microsoft Azure

### Acesso ao Portal Azure

Acessar o portal da Microsoft Azure.

### Localização do Aplicativo Empresarial

1. Pesquisar por: **Aplicativos Empresariais**.
2. Localizar o aplicativo: `wrike - 18022025`.

### Atribuição de Usuário ao Aplicativo

1. Acessar a opção **Atribuir Usuários e Grupos**.
2. Selecionar: **Add User/Group > Usuários**.
3. Pesquisar o nome do colaborador.
4. Selecionar o usuário correspondente.
5. Clicar em **Atribuir** para finalizar a liberação de acesso.
