# Bloquear e-mail e/ou domínio

Acesse o portal do Microsoft Security para realizar o bloqueio de e-mails ou domínios indesejados.

## Procedimento

1. Acessar a aba **Domínio e Endereço de E-mail**.
2. Clicar em **Adicionar**.
3. Selecionar a opção **Bloquear**.
4. Inserir o e-mail ou domínio que deverá ser bloqueado.
5. Na opção "Remover entrada de bloqueio após", selecionar **Nunca expirar**.
6. Clicar no botão **Adicionar**.
7. Verificar se a política foi atribuída/aplicada corretamente.
