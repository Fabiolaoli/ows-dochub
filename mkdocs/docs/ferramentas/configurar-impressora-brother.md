# Configurar Impressora (Modelo Brother)

Instalação e configuração de impressoras em estações de trabalho corporativas, garantindo o correto funcionamento da impressão para o colaborador.

## Procedimento Padrão

1. Ligar a impressora.
2. Identificar o modelo do equipamento.
3. Localizar e instalar o software/driver correspondente na máquina do colaborador.
4. Configurar a conexão da impressora:
   - Via rede Wi-Fi; ou
   - Via cabo de rede.
5. Após a instalação, realizar uma impressão de teste para validar o funcionamento do equipamento.

## Impressoras sem Tela de Configuração

Para modelos que não possuem tela de suporte/configuração:

1. Conectar a impressora diretamente via cabo de rede.
2. Identificar o modelo através da etiqueta do equipamento.
3. Baixar e instalar o software/driver correspondente.
4. Realizar uma impressão de teste para confirmar o funcionamento correto da impressora.
