# Liberar acesso ao OlosAI

## Acessar a plataforma

Acesse o endereço `oat.olos.live`. Em seguida, faça login utilizando o Olos ID.

## Criar o usuário

1. No menu da plataforma, acesse **Configurações Gerais da Plataforma**.
2. Clique em **Novo Usuário**.
3. Preencha os dados do usuário:
   - **E-mail**: inserir o e-mail corporativo do usuário. Exemplo: `joao.silva@olos.com.br`
   - **Nome**: inserir o nome do usuário no padrão nome.sobrenome. Exemplo: `joao.silva`
4. Ative a opção **Provedor Externo**.
5. Clique em **Continuar**.

## Definir o perfil

1. Na etapa **Perfis**, selecione o perfil **Analyst**.
2. Clique em **Continuar**.

## Selecionar as organizações

Na etapa **Organização**, selecione:

- OAT
- TEST
- TESTE12345

Após selecionar as organizações, clique em **Continuar**.

## Configurar os produtos

Na etapa **Produtos**, não é necessário selecionar nenhuma opção. Clique em **Continuar** para finalizar o cadastro e liberar o acesso ao OlosAI.
