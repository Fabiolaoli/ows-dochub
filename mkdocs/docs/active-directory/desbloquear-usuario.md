# Desbloqueio de usuário

Para realizar o desbloqueio da conta de um colaborador no Active Directory, siga o procedimento abaixo.

## Procedimento

1. Abrir o Active Directory.
2. Clicar com o botão direito na rede `intra.olos.com.br`.
3. Selecionar a opção **Localizar**.
4. Pesquisar o nome do colaborador.
5. Selecionar o usuário localizado.
6. Acessar a aba **Contas**.
7. Marcar a opção **Desbloquear conta**.
8. Clicar em **Aplicar**.
9. Finalizar clicando em **OK**.
