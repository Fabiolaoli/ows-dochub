# Alteração de Perfil

Atualização das informações organizacionais de colaboradores no Active Directory Users and Computers, garantindo que os dados de departamento e gestor estejam corretos no ambiente corporativo.

## Procedimento

1. Receber o chamado contendo as informações de alteração do colaborador.
2. Acessar a ferramenta Active Directory Users and Computers.
3. Localizar o usuário do colaborador através do nome ou login de usuário.
4. Abrir as propriedades do usuário.
5. Acessar a aba **Organização**.
6. Atualizar os seguintes campos:
   - **Departamento**: inserir a nova área do colaborador.
   - **Gestor**: selecionar o novo gestor informado no chamado, quando aplicável.
7. Confirmar se todas as informações estão corretas.
8. Clicar em **Aplicar** e, em seguida, em **OK** para salvar as alterações.
9. Registrar no chamado que a atualização foi realizada com sucesso.
