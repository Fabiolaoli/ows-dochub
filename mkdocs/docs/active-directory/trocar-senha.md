# Processo de troca de senha de usuário

Redefinição de senha de usuários no Active Directory (AD), garantindo a atualização segura das credenciais de acesso e a obrigatoriedade de alteração da senha no próximo login do colaborador.

## Redefinição de Senha no Active Directory

### Acesso ao Active Directory

Abrir o Active Directory Users and Computers (AD).

### Localização do Colaborador

No domínio `intra.olos.com.br`:

1. Clicar com o botão direito sobre o domínio.
2. Selecionar a opção **Localizar (Find)**.
3. Pesquisar o nome do colaborador desejado.

### Redefinição de Senha

1. Localizar o usuário na pesquisa realizada.
2. Clicar com o botão direito sobre o colaborador.
3. Selecionar a opção "Redefinir Senha".
4. Definir a nova senha de acesso.
5. Marcar a opção: **O usuário deve alterar a senha no próximo login**.
6. Clicar em **OK** para concluir o processo.
