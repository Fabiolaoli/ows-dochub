# Desativação de Usuário

Desativação de contas de colaboradores no Active Directory e no Microsoft 365 Admin Center, garantindo o bloqueio de acesso aos recursos corporativos.

## Desativação da Conta no Active Directory

1. Acessar o Active Directory.
2. Clicar com o botão direito na rede `infra.olos.com.br`.
3. Selecionar a opção **Localizar**.
4. Pesquisar o nome do colaborador e clicar em **Localizar Agora**.
5. Clicar com o botão direito sobre o nome do colaborador.
6. Selecionar a opção **Desabilitar Conta**.

> ⚠️ **Revisar:** O documento original cita `infra.olos.com.br` neste procedimento, enquanto os demais procedimentos de Active Directory usam `intra.olos.com.br`. Confirmar qual é o domínio correto antes de padronizar.

## Bloqueio de Acesso no Microsoft 365

Acessar o portal Microsoft 365 Admin Center para bloquear o acesso do colaborador.

### Procedimento

1. Pesquisar o nome do colaborador.
2. Selecionar o usuário desejado.
3. Clicar na opção **Bloquear entrada**.
4. Marcar a opção "Bloquear a entrada deste usuário".
5. Clicar em **Salvar alterações**.
