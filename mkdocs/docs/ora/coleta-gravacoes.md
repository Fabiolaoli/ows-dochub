# ORA – Coleta de Gravações

Localização e validação de gravações armazenadas no ambiente ORA, utilizando registros de acesso do Graylog e reprodução de arquivos pelo VLC media player.

## Procedimento

1. Acessar o Graylog utilizando as credenciais de administrador.
2. Pesquisar pelo IP informado no chamado.
3. Filtrar os registros conforme a data e horário informados.
4. Identificar o usuário através dos logs de acesso.

## Acesso ao ORA

1. Acessar o servidor ORA pelo ID `10.197.150.60` utilizando as credenciais de administrador.
2. Selecionar o disco de armazenamento.
3. Acessar a pasta **ORA**.
4. Navegar até o diretório correspondente ao:
   - Ano
   - Mês
   - Dia

   conforme informado no chamado.
5. Localizar a pasta do usuário identificado no Graylog.
6. Procurar a gravação no horário aproximado informado.

## Abertura e Validação das Gravações

1. Acessar:
   - Disco de armazenamento
   - Pasta ORA
   - Ano desejado
   - Mês desejado
   - Dia desejado
2. Clicar com o botão direito sobre o arquivo.
3. Selecionar:
   - 7-Zip
   - Open Archive
4. Localizar a pasta do usuário.
5. Identificar a gravação correspondente ao horário mencionado.
6. Abrir o arquivo utilizando o VLC media player.
7. Validar as imagens necessárias, podendo ser necessário abrir mais de um vídeo até localizar o momento exato solicitado.

## Finalização

1. Salvar o vídeo no ambiente ORA.
2. Registrar no Wrike que as imagens foram localizadas.
3. Entrar em contato com o solicitante para apresentar as imagens:
   - Presencialmente; ou
   - Via Microsoft Teams.

> **Observação:** As imagens nunca devem ser enviadas diretamente ao solicitante.
